# SimeApp
Ao abrir o aplicativo faça seu login como supervisor, ou operador. a senha inicial é 123.
Ao Logar como operador, voce entrara na pagina onde pode escolher uma maquina e cadastras um erro e uma breve descrição.
Ao logar como supervisor, voce vera o dashbord, mostrando o total mensal de maquinas que entraram para manutenção e sairam dela, clicando na maquina desejada, no fim da pagina podera alterar de pendente para resolvido 
O banco de dados registra todo o mes, e mostra no dashbord essa relção.
